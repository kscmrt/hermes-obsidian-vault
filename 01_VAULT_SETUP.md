# Obsidian Vault Setup - Agent OS Sistemi

## Proje Amacı
Hermes AI Agent'in kalıcı hafıza sistemi. Her konuşma sonunda öğrendiklerim burada saklanıyor.
Yeni oturumlar başında bu vault'u okuyarak bağlam alıyorum.

## Yapı (PARA + Agentic OS)
- **01 Projects** — Şu anda çalışan projeler
- **02 Areas** — Uzun vadeli alanlar (YouTube, SEO, Development)
- **03 Resources** — Referans materyalleri, tools, API keys
- **04 Archive** — Tamamlanan işler
- **Wiki** — İnsanlar, şirketler, tools, konseptler
- **Agentic OS** — Agent'lerin kararları, workflow'lar, goals

## Kurulum Kuralları
1. **Root'ta hiç dosya yok** - Her şey bir klasöre gidiyor
2. **Inbox first** - Yeni şeyler Inbox'a iniyor, sonra yer değiştiriyor
3. **Her agent kendi klasörü** - Hermes, Claude, OpenCode vs.

## Protocol File
Her agent başlamadan önce:
1. About.md oku (kim ben, ne işim yapıyorum)
2. Projects.md oku (şu anki hedefler)
3. Vault'ta arat (varsa cevap var)
4. İşi tamamla
5. Sonuç vault'a yaz (append, override etme)
